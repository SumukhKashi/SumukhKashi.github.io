# Sumukh Kashi — Portfolio

A static portfolio built with HTML and CSS. No JavaScript, frameworks, dependencies, or build step.

## Update content

Edit `index.html` for content and `styles.css` for appearance. Replace `resume.pdf` to update the downloadable resume.

## GitHub Pages

Repository: `SumukhKashi/SumukhKashi.github.io`

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, then Save.

Website: https://sumukhkashi.github.io/

## Local preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.
